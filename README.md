# simple-calculator

A simple calculator built with HTML, CSS, and JavaScript.

This project is a lightweight browser-based calculator with a clean RTL Arabic interface. It is designed for basic arithmetic operations and serves as a simple front-end example.

## Features

- Addition, subtraction, multiplication, and division
- Decimal number support
- Clear and delete actions
- Arabic RTL interface
- Lightweight, dependency-free front-end project

## Project Structure

- `index.html` — calculator layout
- `style.css` — visual design and responsive layout
- `script.js` — calculator logic and operations

## How to Run

Open `index.html` directly in your browser.

Alternatively, you can serve it locally:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
