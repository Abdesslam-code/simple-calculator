# simple-calculator

A simple calculator built with HTML, CSS, and JavaScript.

This project provides a lightweight browser-based calculator with a clean Arabic RTL interface. It supports basic arithmetic operations and is suitable as a learning example for front-end web development.

## Features

- Addition, subtraction, multiplication, and division
- Decimal input support
- Clear and delete actions
- Responsive layout for browser use
- Arabic RTL interface

## Project Structure

- `index.html` — calculator layout
- `style.css` — styling and layout
- `script.js` — calculator logic

## How to Run

Open `index.html` directly in a browser.

To run it with a local web server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
